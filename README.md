## Descrição da Solução
O programa desenvolvido em linguagem C lê dados de consumo de água a partir do arquivo `consumo_campus.txt`, calcula a quantidade total de locais analisados, a soma total do consumo, o consumo médio por ambiente, identifica o local com maior consumo de água e contabiliza os locais em situação de alerta (consumo acima do limite recomendado). Por fim, exibe os resultados no terminal e salva um resumo formatado no arquivo `relatorio_consumo.txt`.

## Como Executar
1. Certifique-se de que o arquivo `consumo_campus.txt` está no mesmo diretório do arquivo `.c`.
2. Compile o programa usando um compilador C.
3. Execute o programa gerado.
4. Verifique o resultado exibido na tela e o arquivo `relatorio_consumo.txt` gerado.
